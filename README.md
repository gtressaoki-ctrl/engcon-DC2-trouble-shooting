# engcon DC2 アラーム トラブルシューティング

engcon MicroConf DC2 のアラーム（Id 0〜172）について、原因とトラブルシューティング手順を日本語で検索できる静的 Web アプリです。

MicroConf の「Alarms」画面に表示される **Id** をそのまま入力すると、該当アラームの詳細が表示されます。

## 主な機能

- **エラー番号検索** — Id（0〜172）を入力してすぐ表示
- **キーワード検索** — 日本語・英語コードのどちらでも検索可能（例:「ジョイスティック」「SHORT」「CM-X1」）
- **カテゴリ検索** — PWM出力／ジョイスティック／ツールロック／チルトローテーターモジュールなど 9 カテゴリ
- **対処手順チェックリスト** — 手順を 1 つずつチェックしながら進められます（進行状況はブラウザに保存されます）
- **判断しやすい表示** — 各アラームに次のバッジを表示
  - 種別: 短絡（ショート）／断線（オープン）／較正エラー／通信異常 など
  - 対象者: まずお客様で確認できます／点検が必要（販売店・サービス推奨）／サポートへ連絡
  - リセットにシステム再起動が必要なアラームの明示
- **関連アラームへのリンク** — 例: PWM1 短絡 ⇔ PWM1 断線 の相互参照

## 使い方

サーバー不要の静的サイトです。`index.html` をブラウザで開くだけで動作します（オフラインでも使用可能）。

### GitHub Pages で公開する場合

1. リポジトリの **Settings → Pages** を開く
2. **Source** で「Deploy from a branch」を選択
3. 公開したいブランチと `/ (root)` を選択して保存
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

## ファイル構成

```
index.html          … 画面の枠組み
css/style.css       … スタイル（engcon ブランド調: イエロー × ブラック）
js/alarms-data.js   … アラームデータ（Id 0〜172、日本語訳）
js/app.js           … 検索・一覧・詳細表示のロジック
```

## データの更新方法

アラームの文言を修正する場合は `js/alarms-data.js` を編集してください。
同じ文面を共有するアラーム（ジョイスティック系など）は、ファイル冒頭の共通文 `TXT` と生成ヘルパー関数でまとめて定義されています。

## 注意事項

本アプリは engcon MicroConf DC2 のトラブルシューティング資料（英語）を日本語訳した**非公式の参考ツール**です。
点検・修理作業は必ず機械を安全な状態にしてから行い、判断に迷う場合は販売店・サービスにご相談ください。
